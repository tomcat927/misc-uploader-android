# misc-uploader-android

杂物数字仓库的 Android 上传客户端：双窗口文件管理器（左=手机文件，右=远程目录），多选一键跨侧上传，可靠后台队列。原生 Kotlin + Jetpack Compose。

> 单人自用工具，侧载分发。服务端为 [tianyi-misc-repo](https://github.com/tomcat927/tianyi-misc-repo)（私有仓）的 OpenList 热层架构；Windows 桌面端见 [misc-uploader](https://github.com/tomcat927/misc-uploader)。

## 功能（V1 已实现，设计见 DESIGN.md）

- 双窗口：左侧手机文件 / 右侧远程目录树，触摸聚焦、一键展开单侧、面包屑导航（交互规则见下「使用说明」）；类型过滤、排序菜单、多选全选、目录统计（MT 管理器同款能力）
- 多选 → 一键跨侧上传，落点完整路径确认；文件夹按内部结构展开；上传模式可切「按日期自动归类」（auto/年/月）
- root 桥：root 设备可直接浏览 `Android/data` 等受限目录并批量上传（首次经 Magisk 授权，不受 SAF 13+ 限制影响）
- 检索（MT 同款）：目录内实时过滤（与类型/排序叠加）+ 全局搜索页——关键词通配符、类型、时间范围、递归开关，结果页直接批量入队，点行跳转定位
- 文件查看：图片（双指缩放/同目录翻看）与文本（编码识别/分块加载）内置查看，其余类型交系统应用打开
- 系统分享接收：任意应用"分享到杂物上传"，自动入队到仓库根目录
- 可靠上传队列：前台服务、并发上传、失败自动重试（2s/8s/30s 退避）、内联进度、暂停/继续（杀进程后仍保持暂停态）
- SHA-256 内容级去重 + 上传历史：同内容（无论存到哪个目录）再次上传自动跳过并提示已有位置；「队列」页可切换查看上传历史（本地上限一万条）
- PiGallery2 深链：设置相册地址后，远程目录一键在浏览器打开对应相册页（相册根 = 仓库热层根）
- 上传设置：并发数、最大重试、仅 Wi-Fi（蜂窝下自动暂停、恢复续跑）、分享接收默认目录
- 归档状态卡：队列页显示待归档/冷层文件数与最近同步时间（需服务器脚本每轮写状态文件）
- 应用内热更新：检查 → 下载（进度）→ SHA-256 校验 → 系统安装器；启动自动检查可开关
- 纯 REST 协议（OpenList）：流式上传、内存恒定；专用 chroot 账号，密码 Keystore 加密存储
- 诊断：上传日志 + 应用历史退出原因，应用内查看与复制

V1.1 候选（未实现）：R8 混淆、Room DAO 测试、热更新下载改 WorkManager（杀进程续传）。

## 安装

到 [Releases](../../releases) 下载 APK（附 sha256 校验；国内可用 Release 内的 gh-proxy 加速直链）。

首次运行：设置页填 OpenList 地址（`https://…:5245`）、用户名、密码 → 连接。
建议为 App 建专用账号（base_path 限定 `/misc`，最小权限），不要用 admin。

### 连不上？（ECONNREFUSED 排查）

真机踩过的坑（2026-10-05）：**手机上的代理/VPN（Clash 类）会导致连接被拒**——app 报 `socket failed: ECONNREFUSED`，同时更新检查报"无法连接更新源"。判断方法：连不上时用手机浏览器开同一地址，浏览器也打不开 = 网络/代理问题。处理：关代理测试，或在代理规则里给服务器 IP 加 DIRECT 直连（国内 IP 本就该直连；GitHub 更新源则相反需要走代理）。地址务必**带端口**（`:5245`）——不填端口会连默认 443，同样被拒。

另一个真机坑：**MIUI「联网控制」按应用断网**——被控应用的连接一律 `ECONNREFUSED`（同设备浏览器正常）。检查：设置 → 应用管理 → 杂物上传 → 联网控制（WLAN 和数据都允许）；省电策略建议"无限制"。

## 使用说明

### 双栏触摸聚焦（左右两栏只有一栏「聚焦」，重要）

同一时刻两栏中只有一栏处于聚焦态，规则不同：

- **聚焦侧**：单列列表（行高较大，适合逐项查看/操作）；顶部指示条与「本地/远程」标题为主题色高亮
- **非聚焦侧**：自动变两列紧凑网格（当总览用，一屏看更多条目）；底部操作条为灰色

因此**左栏（本地）变成两竖排 = 聚焦在右栏**。这是设计行为，不是显示异常。

- 切换聚焦：在目标栏**点任意位置**即可（文件、空白处、面包屑都算，整栏都是触摸区）
- 恢复左栏单列：在左栏任意位置点一下，聚焦即回到左栏
- 不想用这个机制：设置页「**双栏触摸聚焦**」开关（默认开）可关闭——关闭后两栏均保持单列列表，点击只切换高亮颜色、不再改变布局
- 与「展开」无关：栏顶「展开」按钮是把另一栏压成窄条进入单侧全屏（400ms 动画），用屏幕边缘的把手恢复双栏；聚焦变化不压缩任何一栏

### 系统返回键

返回键**逐级返回，不直接退出**：设置/队列页 → 回「文件」页；单侧展开态 → 恢复双栏；多选态 → 退出多选；子目录 → 返回上级（按当前聚焦栏）；已在根目录时按返回提示「再按一次返回退出应用」，2 秒内再按才退出（防误触）。弹窗（文件查看器/新建文件夹/上传确认）打开时，返回键先关闭弹窗。

### 显示隐藏文件

设置页「显示隐藏文件」开关（**默认关**）：控制以「.」开头的文件/文件夹（如 `.android`）在两侧列表的显示，本地与远程同规则；切换**即时生效**（无需刷新），图片翻看列表同步遵循该开关。

### 远程整理（移动 / 删除）

右栏（远程）**长按进入多选**，底部操作条出现「移动到…」和「删除」：

- **移动到…**：弹目录选择器（从仓库根起导航，仅列目录），选好点「移动到这里」；目标不能是当前目录，也不能是 `auto/` 根目录
- **删除**：红色确认框明示完整路径清单；文件夹会**连同内容一起删除**
- **保护规则**：仓库根 `auto/` 目录本体受保护（不能选中、移动或删除），其下的文件和子目录可自由整理
- **误删兜底**：可在存储云盘的网页端回收站尝试恢复（保留期由云盘决定）；app 内撤销式回收站为后续增强
- **权限**：需要账号具备移动/删除权限位——报 `403 PermissionDenied` 时到 OpenList 后台为账号补权限

### 文件查看与打开

- 单击文件按类型路由（多选模式下单击仍是勾选，不进查看器）：
  - **图片** → 内置查看器：双指缩放（1–6 倍）、左右滑动翻看同目录图片，返回键关闭
  - **文本** → 内置只读查看（MT 管理器风格：白底黑字 + 行号 + 头部信息条显示文件名/编码/行数，点行高亮；自动识别编码，大文件分块「加载更多」）；远程文本超过 50MB 不进入查看器（打开前预检，不整文件下载）
  - **其他类型**（视频/PDF 等）→ 本地单击**直接弹系统「打开方式」选择器**（MT 管理器同款，每次选应用）；远程先下载（弹窗内进度，完成自动关页）再弹选择器；远程图片经 raw_url 直连不落盘，远程文本/其他先下载到应用缓存（系统"清除缓存"可回收）
- 查看器为全屏弹窗，盖住底部导航，系统返回键 = 关闭

### 应用更新

- 设置 → 「应用更新」卡片：手动「检查更新」，发现新版本弹窗确认后**在同弹窗内显示下载进度**（可「后台下载」收起，设置卡片同显进度；SHA-256 校验），下载完成自动拉起系统安装器；未授权「安装未知应用」时会先跳授权页，授权返回后点卡片「安装」继续
- 「启动时检查更新」开关默认开：启动后延迟数秒静默检查，发现新版本同样弹窗询问；**每个版本只弹一次**——启动弹窗点「暂不」会记住该版本，之后冷启动只显示顶部轻提示（主动「检查更新」不受影响，每次都弹）；出新版本后弹窗恢复
- 更新经 gh-proxy 加速；关闭启动检查后启动完全不发起更新源请求

## 构建

本机零环境：构建/签名/发布全部在 GitHub Actions。push 到 master 即自动构建并发布 Release（`v{version}-{buildtime}`），保留最近 10 个。签名 keystore 走 Actions secrets（`ANDROID_KEYSTORE_BASE64` 等），未配置时使用 debug 签名（可装可测，与正式签名版不能互相覆盖安装）。
